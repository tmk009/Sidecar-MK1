# Credits

Inspired by [Sidecar Expander](https://trigcondition.github.io/sidecar-expander/),
by trigcondition and contributors.

The HTML, CSS, small video script, SVG mark and explanatory text in this
website were prepared for the MK1 project. No upstream website theme, logo,
screenshots, video, DSP source or preset table is bundled here. The original
site informed the page structure; this site describes our MK1 feature scope.

The musical prototype described on these pages uses DSP components from
Sidecar Expander and other authors, including Emilie Gillet's Plaits/stmlib,
mdkit, AMY-derived patch data and DaisySP. That implementation is not wholly
independently rewritten and is not distributed in this website snapshot.
Its original attribution and licenses remain with the development sources;
a future software distribution must address those components separately.

The publishing workflow invokes GitHub's hosted Actions. An optional video
embed uses YouTube when configured; neither service's implementation is
bundled as part of this website.
