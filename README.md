# Sidecar MK1

Seven digital machines for the Analog Rytm MK1.

Explore the machines, features and setup instructions on the
[project website](https://tmk009.github.io/Sidecar-MK1/).

- [Machine overview](https://tmk009.github.io/Sidecar-MK1/)
- [Setup and status guide](https://tmk009.github.io/Sidecar-MK1/guide.html)
