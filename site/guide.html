What you’ll need

  • Analog Rytm MK1, original OS 1.74. Other OS versions and MKII are outside this scope.
  • A Raspberry Pi and the matching receiver. The exact supported Pi model and OS image will be specified after fresh-install testing.
  • A USB connection, Pi power and the Rytm’s audio outputs. The Pi generates audio and returns it over USB to the Rytm track path.
  • Your own original firmware and backups. No Elektron firmware or personal samples are distributed.

The planned release will generate a separate patched image from the original firmware, preserving the original file. The release will include installation instructions and steps to return to the original firmware.

Current limitations

  • GRAIN is excluded. Active machines: PLAITS, MD, ACID, WAVEPAD, JUNO, PLUCK and SAMPLE.
  • Twelve tracks share eight physical voices and native choke relationships.
  • SAMPLE DIR does not yet support native parameter locks. Some factory sample sources are inaccessible.
  • Continuous modulation uses control-rate updates up to 50 Hz per track, not audio-rate modulation.
  • Testing is ongoing for all models and controls, including extreme resonator and PLUCK settings, JUNO patch A82 and saved JUNO settings.
  • MD retriggering passed its listening test. Testing of all MD models and parameter locks is ongoing.
  • End-to-end device latency has not been established for this release.
